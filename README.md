# Sistema de Loja Virtual em PHP

Projeto desenvolvido em PHP, HTML, CSS, JavaScript e MySQL com funcionalidades de cadastro de usuários, login, gerenciamento de produtos e carrinho de compras.

## Funcionalidades

- Cadastro de usuários
- Sistema de login
- Carrinho de compras
- Cadastro de produtos
- Edição de produtos
- Exclusão de produtos
- Gerenciamento de usuários

## Tecnologias utilizadas

- PHP
- HTML
- CSS
- JavaScript
- MySQL

## Objetivo

Este projeto foi desenvolvido com o objetivo de praticar desenvolvimento web utilizando tecnologias front-end e back-end. O sistema simula uma loja virtual, permitindo aplicar conceitos de autenticação de usuários, integração com banco de dados, gerenciamento de produtos e funcionamento de um carrinho de compras.

Além disso, o projeto contribuiu para o aprendizado de organização de código, estruturação de páginas web e desenvolvimento de aplicações dinâmicas utilizando PHP e MySQL.
